# 🐍 Python Practice Projects

A collection of beginner-friendly Python projects created to practice programming fundamentals and improve problem-solving skills.

Each project focuses on a different Python concept, helping me build a stronger foundation through hands-on practice.

## 📂 Projects Included

* 🔢 **Even & Odd Numbers** — Checking and working with number classifications
* 🔍 **Prime Number Checker** — Practicing loops, conditions, and mathematical logic
* 📁 **File Handling** — Learning how to read, write, and manage files
* 🧮 **Calculator** — Building basic arithmetic operations
* 📖 **Dictionary Operations** — Working with Python dictionaries and data structures
* 📐 **Area Calculator** — Calculating areas of different shapes
* 🔄 **Unit Converter** — Converting values between different units
* ❌⭕ **XO Game** — Creating a simple Tic-Tac-Toe game
* 🗄️ **Working with SQL** — Learning database fundamentals using SQL and Python
* 🌐 **API** — Building and consuming APIs with Python
* 💬 **Chat Server-Client** — A simple client-server chat application using Python sockets

## 🎯 Purpose

The purpose of this repository is to practice Python fundamentals, improve logical thinking, and develop better programming habits through small practical projects.

These projects are part of my learning journey as I continue exploring Python and software development.
