# 🐍 Learn Python

A hands-on Python learning repository containing exercises, experiments, notes, and small projects built while learning Python and programming fundamentals.

The goal of this repository is to **learn by building** — starting with basic syntax and problem solving, then gradually moving toward APIs, databases, networking, and backend development.

---

```text

│

├── pro/

└── LICENSE
```

### `exercises/`

Small exercises used to practice individual Python concepts.

Examples:

* Variables and data types
* Conditions
* Loops
* Functions
* Lists, tuples, sets, and dictionaries
* File handling
* Error handling
* Object-oriented programming

### `projects/`

Larger projects that combine multiple concepts into something practical.

Current and planned projects include:

* 🎮 **XO** — A simple Tic-Tac-Toe game
* 🔌 **API** — Working with HTTP APIs and JSON
* 💬 **Chat** — Client-server communication using Python sockets

### `notes/`

Personal notes and explanations about concepts learned during the development process.

This repository is primarily a **learning laboratory**.

The projects are not intended to be production-ready applications. Some of them are intentionally simple because their purpose is to practice a specific concept.

As my skills improve, earlier projects may be refactored, expanded, or replaced with better implementations.
