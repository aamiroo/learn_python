# Python P2P Chat

A simple Peer-to-Peer (P2P) chat application built with Python using TCP sockets.

This project was created as a learning exercise to understand the fundamentals of socket programming, TCP communication, and client-server architecture.

## Features

- TCP socket communication
- Client and Server implementation
- Send and receive text messages
- Colored terminal output using Colorama
- Simple and easy-to-read code
- Beginner-friendly project

## Project Structure

```
.
├── server.py
├── client.py
└── README.md
```

## Requirements

- Python 3.X

## How to Run

### 1. Start the server

```bash
python3 server.py
```

### 2. Start the client
```bash
python3 client.py
```
